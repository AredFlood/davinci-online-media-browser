# DaVinci Resolve Studio 面板

这个目录是 DaVinci Resolve Studio 的 Workflow Integration 面板入口。

安装脚本会把它复制到 Resolve 的 Workflow Integration 插件目录。安装完成后，重启 DaVinci Resolve Studio，在菜单中打开：

```text
Workspace -> Workflow Integrations -> Online Media Browser
```

`WorkflowIntegration.node` 由本机 DaVinci Resolve 提供，不随本项目分发。
