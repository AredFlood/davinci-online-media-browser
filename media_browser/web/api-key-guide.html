获取 API Key 教程

你不需要写代码。注册素材平台账号，复制平台给你的一串 Key，然后粘贴到插件对应输入框即可。

打开 Pexels 打开 Pixabay 打开 Freesound
你想搜索什么 建议配置 插件里填写的位置
图片、视频 Pexels、Pixabay Pexels API Key、Pixabay API Key
音效 Freesound Freesound Client Secret
音乐、部分音效 Mixkit 无需 Key，保持启用即可

安全提醒

  • API Key 相当于你的平台访问凭证，不要发到公开群、截图、GitHub 或视频里。
  • 本插件会把 Key 保存在你电脑上的 ~/.davinci_plugins/api_keys.json。
  • 复制 Key 时不要带空格、引号或中文标点。
  • 如果怀疑 Key 泄露，请去对应平台重新生成或删除旧 Key。

Pexels：图片和视频

  1. 打开 Pexels API 页面。
  2. 点击 Get Started，登录或注册免费账号。
  3. 按页面提示申请 API Key。应用名称可以写 DaVinci Online Media Browser。
  4. 复制生成的 API Key。
  5. 回到插件，把它粘贴到 Pexels API Key。
  6. 点击保存，等待输入框变成就绪状态。

Pixabay：图片、视频和部分音乐

  1. 打开 Pixabay API 文档。
  2. 登录或注册 Pixabay 账号。
  3. 登录后，文档页面会显示你的个人 API Key，通常在 key 参数附近。
  4. 复制完整 Key，常见格式类似 12345678-xxxxxxxxxxxxxxxxxxxxxxxx。
  5. 回到插件，把它粘贴到 Pixabay API Key。
  6. 点击保存并等待校验。

Freesound：音效

新手优先填写 Client Secret / API Key。当前插件搜索音效主要依赖这个字段，OAuth Token 可以先不填。

  1. 打开 Freesound API 凭证页面。
  2. 登录或注册 Freesound 账号。
  3. 申请新的 API 凭证。应用名称可写 DaVinci Online Media Browser。
  4. 如果页面要求 Website 或 Redirect URI，可以填 http://localhost。
  5. 提交后，复制 Client Secret / API Key 这一栏的长字符串。
  6. 回到插件，把它粘贴到 Freesound Client Secret。
  7. Client ID 可以一起填，也可以先不填；OAuth Token 可以先不填。
  8. 点击保存并等待校验。

如果 Freesound 校验失败，最常见原因是把 Client ID 误填到了 Client Secret 输入框。

Mixkit：无需 Key

Mixkit 不需要申请 API Key。配置窗口里保持 启用 Mixkit 即可。

Mixkit 属于网页来源，偶尔会受到网页结构变化、地区网络或访问限制影响。如果临时不可用，优先使用 Pexels、Pixabay、Freesound 这些官方 API 来源。

保存后如何判断成功

  1. 点击插件配置窗口右下角的 保存。
  2. 成功后会出现连接成功提示。
  3. 失败时，插件会标出有问题的平台。重新复制 Key 后再保存即可。

可以一个 Key 都不填吗？

可以。你仍然可以保留 Mixkit，但 Pexels、Pixabay、Freesound 对应的搜索结果会不可用或减少。

填错了怎么办？

点击插件左侧的设置按钮，重新打开 Key 配置窗口，修改后保存即可。也可以删除某个平台的 Key。
